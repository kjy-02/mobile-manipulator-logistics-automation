# 모바일 매니퓰레이터 물류 자동화 시스템 — 기술 구성

작성 중인 동명 학사학위논문의 목적·시스템 설명과 현재 코드를 대조해 정리했다. 논문의 미기입 실험 표는 성능 결과로 사용하지 않는다.

## 물류 작업의 목적

차량이 픽업존으로 이동한 뒤 정지하고, 작업대 상자를 인식해 파지·분류 적재하는 작업 흐름을 구성한다. 이동 로봇으로 고정 로봇팔의 작업 위치를 옮기고, RGB-D 인식으로 물품마다 별도의 시각 마커를 부착하지 않는 방식을 사용한다.

논문의 평가 과제는 서로 다른 상자 3개의 순차 처리와 차량 부착 적재함 적재다. 저장소에는 실제 통합 시연과 구현 코드를 제시하며, 반복 시험 횟수·성공률·위치 오차·전체 작업 시간의 정량 결과는 아직 제시하지 않는다.

## 장비의 역할

| 장비 | 역할 |
|---|---|
| SCOUT 2.0 | 물품 작업 위치까지 이동하는 차동 구동 플랫폼 |
| Velodyne VLP-16 | 지도 작성, 위치 추정, 주행 장애물 입력을 위한 3D 점군 |
| xArm5 + 2-finger gripper | 상자 접근, 파지, 이송 및 분류 적재 |
| Intel RealSense L515 | 물체의 RGB 영상과 깊이 정보 취득 |

## 1. 지도 작성과 저장 지도 기반 위치 추정

지도 작성은 사전 단계로 수행한다. `hdl_graph_slam`에서 VLP-16 점군을 전처리하고 FAST_GICP로 스캔 사이 상대 이동을 추정한다. 키프레임과 루프 제약을 자세 그래프에 반영하고 결과 지도를 PCD로 저장한다. 기본 launch의 voxel downsampling 설정은 0.1 m이다.

최종 주행 중에는 새로운 지도를 계속 작성하는 대신 `hdl_localization`으로 실시간 점군과 저장 지도를 정합한다. 현재 구성은 NDT_OMP를 사용하며, RViz에서 초기 위치·방향과 작업대 목표를 지정한다. TF로 목표와 로봇 자세를 같은 기준에서 비교한다.

설정 근거: `third_party/hdl/hdl_graph_slam/launch`, `local_ws/src/scout_dwa/launch/hdl_localization_map.launch`.

## 2. DWA 작업대 접근 주행

실시간 LiDAR 점군에서 장애물 격자를 만들고, 로봇 현재 속도·목표·차체 형상을 DWA에 전달한다. DWA는 속도 후보별 궤적을 예측하고 충돌 후보를 제외한 뒤 목표·장애물·속도 비용으로 주행 명령을 선택한다. 현재 구성은 목표에 대한 국소 접근이며 별도의 전역 우회 경로를 생성하지 않는다.

도착 완료 신호를 받은 연결 프로그램은 차량을 정지시키고 주행 프로그램을 종료한다. 정상 종료 후에만 기존 YOLO/xArm launch를 시작한다. 주행 중 동시에 팔 작업을 수행하는 구조는 아니다.

설정값 예시: 목표 속도 0.55 m/s, 최소 속도 0.1 m/s, 예측 시간 3 s, 도착 거리 기준 0.5 m. 이 값은 소프트웨어 설정이며 실측 속도·정확도가 아니다. 출발 시 가속도 제한 때문에 최소 속도 미만의 후보도 허용하도록 범위를 보정했다.

구현 근거: `local_ws/src/dwa_planner/src/dwa_planner.cpp`, `local_ws/src/scout_dwa/scripts/run_goal_navigation.py`.

## 3. RGB-D 검출과 Eye-in-Hand 관측

L515는 팔 말단에 장착된 Eye-in-Hand 구성이다. 팔이 초기 관측 자세에 도달하면 `/vision_enable`을 켜고, YOLOv8n ONNX 모델을 OpenCV DNN으로 실행해 상자의 클래스와 박스를 얻는다. 박스 안 깊이 영역으로 3차원 상대 위치를 계산하고 목표 정보를 전달한다.

팔 이동 중에는 새로운 목표 TF 발행을 일시 정지해 초기 관측 자세에서 선택한 물체를 처리한다. 현재 소스의 클래스는 `red_box`, `yellow_box`, `blue_box`다. 학습 데이터·학습 결과는 별도로 추가할 예정이다.

구현 근거: `local_ws/src/use_yolo/scripts/yolo_detector.py`.

## 4. 좌표 보정과 xArm 파지·적재

고정된 초기 관측 자세에서 카메라의 상대 좌표와 팔의 현재 위치, 장착 오프셋·스케일 보정값을 조합해 파지 위치를 계산한다. 관측 자세가 달라지면 이 대응도 다시 확인해야 하며, 일반적인 모든 자세에 대한 외부 파라미터 보정을 완료한 것으로 표현하지 않는다.

코드의 수직 파지 IK는 목표 수평 위치로 J1을 결정하고 J5 연동값을 정한 뒤, J2·J3·J4를 수치 자코비안과 감쇠 최소제곱 방식으로 반복 계산한다. 파지 전 상공 접근, 하강, 그리퍼 닫기, 상승, 분류 적재, 초기 자세 복귀 순서로 연결한다. 초기 자세에서 설정 시간 동안 검출이 없으면 종료 절차를 수행한다.

이 로봇팔 구현은 팀의 조작부 작업이며 김재윤의 개인 담당인 지도 작성·위치 추정·DWA 수정·전체 통합 테스트와 구분한다.

구현 근거: `local_ws/src/use_yolo/scripts/xarm_vision_pick_drop.py`.

## 현재 결과와 작성 중인 논문의 구분

- 실제 야외 주행부터 파지·분류까지의 시연 영상은 `demo-v1` 릴리스에 제시한다.
- 카메라 미송출 문제는 L515의 사용하지 않는 pointcloud 기능 비활성화로 해결했다. 절전 전환과 잔여 프레임 저하의 관계는 사용자 관찰에 따른 추정으로 기록한다.
- 논문 초안의 기존 상자 명칭과 최신 코드의 클래스명이 다르므로 저장소는 최신 코드를 기준으로 한다.
- 논문의 국문·영문 요약 및 본문 일부에는 계획·구현 표현이 혼재하고 실험 표는 비어 있다. 아직 채워지지 않은 성공률·오차·시간은 저장소의 성과로 옮기지 않는다.

자세한 문제 해결 과정은 [통합 문제와 대응](INTEGRATION_DEBUGGING.md)을 참고한다.
