# 출처와 라이선스 기록

- `dwa_planner`: AMSL dwa_planner에서 파생. 기존 `local_ws/src/dwa_planner/LICENSE`의 BSD 3-Clause 고지 유지.
- `scout_dwa`에 포함된 DWA 파생 코드·참고 사본의 기존 LICENSE 파일과 출처 문서 유지.
- `scout_dwa/package.xml` 라이선스 선언: BSD-3-Clause.
- `use_yolo/package.xml` 라이선스 선언: MIT. 이번 배포 작업에서는 새로운 권리자나 저작권 고지를 임의로 만들지 않았다.
- 외부 의존성은 각 저장소의 라이선스를 따른다. 링크와 커밋은 `dependencies.repos` 참조.

ONNX 모델과 세 PCD 지도는 사용자의 현재 실행 파일을 복사했다. 모델의 학습 데이터·학습 코드·별도 배포 라이선스 정보는 이번 코드에서 확인하지 못했으므로, 저장소 소개를 마무리할 때 사용자가 가진 출처·학습 자료·이용 조건을 추가한다. 임의의 라이선스를 모델·지도에 부여하지 않았다.

패키지 내부의 과거 README와 상태 문서는 기존 자료로 보존했다. 현재 배포 구성은 루트 README와 EXPORT_NOTES를 기준으로 한다.
