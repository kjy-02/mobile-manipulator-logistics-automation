# 출처와 라이선스 기록

- `dwa_planner`: AMSL dwa_planner에서 파생. 기존 `local_ws/src/dwa_planner/LICENSE`의 BSD 3-Clause 고지 유지.
- `scout_dwa`에 포함된 DWA 파생 코드와 참고 사본의 라이선스와 출처는 각 디렉터리에서 확인할 수 있다.
- `scout_dwa/package.xml` 라이선스 선언: BSD-3-Clause.
- `use_yolo/package.xml`에는 MIT 라이선스가 선언되어 있다. 배포본은 기존 저작권 고지와 권리자 정보를 따른다.
- 외부 의존성은 각 저장소의 라이선스를 따른다. 링크와 커밋은 `dependencies.repos` 참조.

ONNX 모델과 최초 배포에 포함한 PCD 지도 3개는 실제 실행에 쓰던 파일이다. 이 저장소에서 모델의 학습 데이터와 학습 코드 정보는 확인되지 않는다. 모델과 지도에는 별도 배포 라이선스를 붙이지 않았으며, 출처와 이용 조건을 확인해야 한다.

패키지 안의 이전 README와 상태 문서는 각 시점의 설정을 기록한다. 현재 실행 순서와 배포 구성은 [루트 README](../README.md)와 [배포 기록](EXPORT_NOTES.md)을 참고한다.
